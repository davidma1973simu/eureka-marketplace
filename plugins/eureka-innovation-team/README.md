# Eureka 创新教练团（Eureka Innovation Team）

> 一支覆盖完整创新旅程的 WorkBuddy 专家团：从选题到商业模式，8 位创新专家一站式护航。

## 这是什么
Eureka 创新教练团是由 **1 位总控（顾全程）+ 8 位专家** 组成的专家团队（expert team），基于 RISE 创新方法论，带用户走完「选题 → 用户洞察 → 创意激发 → 方案构建 → 价值评估 → 验证决策 → 演讲呈现 → 商业模式」的全流程。

## 包含的 8 个 Skill
- `eureka-ideation` —— 选题专家：从行业/人群/痛点挖出可落地的创新选题
- `eureka-insight` —— 用户洞察专家：设计访谈、用 FIND 框架挖深层需求
- `eureka-inspire` —— 创意生成专家：交叉激发 12–20 个创意并筛选 Top 5
- `eureka-shape` —— 方案构建专家：四维拷问、设计 MVP 与用户流程
- `eureka-value` —— 价值评估专家：用 AHA/MAP 评估用户与商业价值
- `eureka-exam` —— 验证决策专家：设计最小验证实验，给出 go/nogo/pivot
- `eureka-pitch` —— 电梯呈现专家：生成 30 秒/60 秒/5 分钟演讲
- `eureka-business` —— 商业模式专家：用精益画布梳理商业模式

## 包含的 9 个 Agent
- 总控：**顾全程**（创新旅程总监）
- 成员：寻向远（选题）/ 察入微（洞察）/ 思不凡（创意）/ 谋定行（方案）/ 价知衡（价值）/ 验真金（验证）/ 讲得清（呈现）/ 赢在算（商业）

## 如何使用
1. 在 WorkBuddy 左侧「专家」面板中找到 **Eureka 创新教练团**。
2. 点击进入，选择快速提示（如"我有一个想做的方向，帮我走一遍完整的创新流程"），或直接描述你的创新想法。
3. 总控顾全程会调度 8 位专家，按 RISE 阶段逐步推进，每步产出**卡片化**结果。

也可以单独调用任一 Skill（例如直接说"帮我做个用户访谈提纲"即触发 `eureka-insight`）。

## 目录结构
- `.codebuddy-plugin/plugin.json` —— 插件清单（含 `expertType: team` 及成员配置）
- `skills/` —— 8 个创新技能
- `agents/` —— 9 个代理定义（1 总控 + 8 专家）
- `avatars/` —— 团队与成员头像

## 安全说明
本插件全部为本地 Skill 与 Agent 定义，**不发起任何外部网络请求、不安装第三方可执行文件**，仅以用户权限在本地运行，请放心安装。
